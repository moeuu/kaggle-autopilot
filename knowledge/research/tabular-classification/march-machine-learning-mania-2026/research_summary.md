Ranked shortlist for `research_summary.md`

1. Hybrid rating-feature ensemble: leak-free season state from regular-season + conference-tourney data only; features include Elo variants, offense/defense/pace estimates, recent-form windows, seed deltas, Massey aggregates, conference/coach indicators, and matchup diffs/ratios. Models: CatBoost GPU (`loss_function=Logloss`, depth 8, learning_rate 0.03, iterations 4500), XGBoost GPU (`tree_method=hist`, `device=cuda`, depth 8, eta 0.03, 3200 trees), LightGBM GPU (`objective=binary`, depth -1, num_leaves 127, learning_rate 0.03, 3800 trees). Runtime/memory: 90-150 min full search, 8-12 GB RAM, 4-8 GB VRAM. Leakage risk: medium if fold-safe stat encodings are mishandled; low once encoders are fit on train folds only. Fallback: drop LightGBM first, then CatBoost/XGBoost remain strong.

2. CatBoost-first raw categorical pipeline: same feature factory but minimal external encoding; pass team/conference/coach/seed bucket columns directly as categoricals and let CatBoost handle interactions internally. Runtime/memory: 35-60 min, 6-10 GB RAM, 4-6 GB VRAM. Leakage risk: low to medium; mostly from upstream feature joins, not CatBoost itself. Fallback: if CatBoost unavailable, use XGBoost with categorical/stat-encoded replacements.

3. XGBoost stat-encoding pipeline: engineered numeric matchup table plus fold-fit team/conference/coach target/stat encodings, recent-form features, and rating deltas. Runtime/memory: 30-50 min, 6-10 GB RAM, 4-6 GB VRAM. Leakage risk: highest among shortlist because encodings can leak if fit globally; require strict fold-train mapping with global-prior fallback for unseen categories. Fallback: replace stat encodings with raw categorical CatBoost inputs.

4. OOF logit blend: blend shortlisted base models only if honest season-heldout Brier improves; use constrained nonnegative weights learned on OOF predictions, with optional rating-prior anchor. Runtime/memory: cheap after base fits. Leakage risk: low if blend is trained only on OOF predictions from training folds. Fallback: choose the best single model by CV Brier.
